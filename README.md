Proyecto de desarrollo de soluciones robóticas enfocadas en asistencia, interacción humana y aplicaciones clínicas.

## Descripción

Desarrollo de un robot móvil asistencial orientado a la interacción con personas y al apoyo en entornos clínicos, integrando diferentes áreas de la ingeniería y la robótica.

## Tecnologías

- Microcontroladores
- Electrónica
- Robótica
- Diseño mecánico
- Programación
- Automatización
- Sensores y actuadores

## Desarrollo

En este repositorio se almacenan los avances, diseños, códigos, documentación y diferentes elementos desarrollados durante el proyecto.

## Estructura del proyecto

- `Codigo/` → Programación y control del robot
- `Diseño/` → Modelos y diseños mecánicos
- `Electronica/` → Circuitos, esquemas y conexiones
- `Documentacion/` → Información y documentación del proyecto
- `Investigacion/` → Material de investigación y referencias
